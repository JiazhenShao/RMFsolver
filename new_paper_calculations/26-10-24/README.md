# Numerical nonrelativistic adiabatic contour at T(0+) = 0.1 MeV

This folder copies the numerical radial-shell/angular-wavefront workflow from
`../26-08-21/` and calls `phase_velocity.solve_front_adiabatic_slow`.
It conserves `u*nB`, pressure, and `h*u`, uses the full neutral quark EOS, and
fixes the interface temperature to 0.1 MeV. No analytical velocity or analytical
initial-guess calculation runs in this workflow. Unrelated analytical entry
points from the old shared helpers have been omitted.

The calculation uses massless quarks (`ms=0`), massive QMC-RMF3 PNM upstream,
`B_one_forth=189.1565957288247` MeV, and the original cold `3*n0` calibration.
The current solver supplies `alpha_s=0.4`, the exact `h_D`, and the prescribed
weak-rate prefactor `(muB/3)**5`.

## Inputs and numerical seeds

`inputs/relativistic-state-of-art.npy` is an unchanged copy of
`../26-08-24/T0plus0p1-uNmax-state-of-art-complete-5km.npy`.
Its complete **30-angle by 18-column display grid** supplies both the target
upstream coordinates and their exact historical numerical baryon flux guesses.
The original 600-cell scan is not the completed reference: its outer cells had
failures, and the consolidated contour replaces them with an adaptive outer
column. The later September scans use a different `4*n0` calibration.

`inputs/legacy-domain.npy` copies the August 21 geometry metadata.
`T0plus0p1-domain.npy` is the prepared 540-point target manifest, generated by
`prepare_T0plus0p1_domain.py` without any EOS or analytical solves. It retains
source indices, fluxes, and SHA-256 provenance. The grid's historical boundary
metadata is **sampling provenance**, not an asserted nonrelativistic physical
boundary. The final column has angle-dependent radial fraction; use each
point's `radial_fraction_used` or the physical coordinate grids, rather than
interpreting the legacy one-dimensional radial axis as universal.

Historical velocities and success flags are never imported as new results.
Their rate/coupling history can differ from current microphysics, so a speed
difference against this saved reference is not a pure relativity comparison.
Its old 5000 m/s contour coverage is also not assumed for the new solution.

## Run on the cluster

Copy this directory together with the current `RMFsolver/` directory, preserving
the repository layout. Python with NumPy, SciPy, matplotlib, and tqdm is needed.
The local verification runtime is Python 3.12 / SciPy 1.18.1.
From the repository root:

```bash
python3 new_paper_calculations/26-10-24/run_T0plus0p1_numerical.py --workers 16
python3 new_paper_calculations/26-10-24/plot_T0plus0p1_numerical.py
```

The numerical command writes `T0plus0p1-adiabatic-slow.npy` in this folder;
the plot command writes `T0plus0p1-adiabatic-slow-contour.png` and `.pdf`.
The prebuilt domain is ready to use. Run the preparation script only when
reconstructing it; it refuses to overwrite an existing file.

For a quick six-point end-to-end check:

```bash
python3 new_paper_calculations/26-10-24/run_T0plus0p1_numerical.py --smoke --workers 3
```

`--smoke` uses a separate `-smoke.npy` output. `--output` selects another file;
relative paths are resolved within this folder. `--restart` creates a suffixed
output instead of replacing an existing calculation. A supplied result file
allows plotting on another machine without the solver runtime.

On this Mac, the isolated SciPy runtime is selected from the repository root by:


## Continuation, accuracy, and recovery

The first shell starts from the historical same-point numerical flux. Later
shells first extrapolate newly accepted nonrelativistic profiles along the same
angle. If a radial predecessor failed, a newly accepted immediate-angle profile
can supply the normalized shape. If needed, the inherited angular wavefront, flux perturbations,
historical scalar fallbacks, and bounded midpoint bridges recover failed targets.
There is no 1 MeV bootstrap and no reuse of old relativistic profiles.

New profiles store physical fields plus a separate `continuation_state` using
the solver's normalized integrated-density/current fields. Every trial copies
that state and replaces its `jB` with the actual candidate flux; the solver gives
the continuation state's flux precedence over its standalone guess argument.

Defaults: `tail_eps=1e-8`, `n_mesh=300`, `tol_bvp=1e-4`, `max_nodes=50000`,
`path_rtol=1e-6`, `kappa_factor=1`, 300 seconds per disposable child process,
1200 seconds per target, and at most two bridge levels. Each child is terminated
before a timed-out trial is replaced. Workers default to the scheduler allocation
or available CPU count; set `--workers` explicitly for a local run.

For the specific error `Slow-front EOS/diffusion table did not converge`, the
wrapper retries with table tolerances `0.5`, `0.2`, and `0.1` times the requested
value, within the same hard trial deadline. This resolves a demonstrated
14-round table-refinement exhaustion; it does not loosen any acceptance gate.
Each effective tolerance and message is saved in `path_refinement_attempts`.
The midpoint reference check at grid `(15,8)` agreed across tighter tolerances
to better than `2e-10` relative flux.

At one cold upstream density, the standard RMF starting guesses find only one
physical solution and therefore fail the required two-start agreement check.
Only after that failure, the child temporarily adds starts `(35,25,-3)` and
`(40,30,-3)` for `(sigma,w0,r03)`. Both independently recover the same physical
branch with the original RMF residual, density, and branch-agreement gates.
The original seed tuple is restored in `finally`; no solver source or EOS
equation is changed. `upstream_seed_extension` and the attempt history disclose
this recovery. No input temperature or density is perturbed.

Accepted results require the correct model, successful collocation, positive
flux, the requested interface temperature, conservation and EOS closure errors
at most `1e-8`, boundary errors at most `1e-7`, and physical diffusion/reaction
residuals at most `max(5*tol_bvp,1e-7)`.

## Checkpoints and output interpretation

Checkpoints are atomic and saved after each terminal cell with its physical
profile, continuation state, attempts, and diagnostics. Restarting the same
command resumes unfinished scheduling. Physics inputs, prepared-domain bytes,
solver/helper source hashes, and numerical settings must match before an
existing checkpoint is accepted, including a completed one. Different code or
settings require `--restart` or a new output name.

`run_complete` / `scheduling_finished` mean all targets have been attempted;
`all_targets_successful` reports whether all were accepted. Exit status is zero
only when every target succeeds; otherwise it is two. Terminal failures are
preserved rather than silently retried on resume. The old `numerical_outward_*`
array keys are retained for compatibility, with explicit new-model metadata.
Legacy upward/downward container aliases are retained; no temperature sweep or
hysteresis comparison is performed here.

`complete_5000_contour_bracket` is computed afresh from new speeds bracketing
5000 m/s along every angle. A complete 540-point grid need not satisfy it.
The plotter uses only accepted new-model speeds on their actual upstream grid,
refuses incomplete input by default, and can explicitly show masked partial
results with `--allow-partial`. It does not extrapolate beyond sampled points.

Regression checks live in `tests/test_nonrel_adiabatic_cluster.py`; run them with
`python3 -m unittest discover -s tests -p test_nonrel_adiabatic_cluster.py`.

## Verified local result, 2026-10-24

The delivered standard payload has **540/540 accepted points**, with no timed-out
trials. All 10 migration tests and the six-point smoke scan pass. The final run
used the tighter table retry at 145 points and additional RMF starts at one point.
Maximum relative pressure and enthalpy-flux errors are `5.805e-9` and `1.806e-10`.
All saved profile rates match the revised formula within `4.45e-16` relative,
and sampled diffusion values match direct evaluations within `1.12e-16`.
Six representative tighter reruns, including a changed flux guess, alter speeds
by at most `4.134e-7` relative. Detailed checks are in `verification.json`.

Speeds span **30.20 to 4023.32 m/s** on this inherited grid. The grid is complete,
but the new 5000 m/s contour is outside its coverage. The figure shows only
supported speeds and does not reuse the historical 5000 m/s boundary as a new one.
