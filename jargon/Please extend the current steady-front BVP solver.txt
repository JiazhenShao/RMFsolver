New physics to add
------------------
I want to solve the enlarged steady system:

    d/dx [ u(x) nB(x) ] = 0
    d/dx [ h(x) u(x)^2 + P(x) ] = 0
    d/dx [ DQ(x) d/dx a(x) - u(x) a(x) ] = R(a; x)
    d/dx [ s(x) u(x) ] = (nB_Q / T(x)) * muK(x) * R(a; x)

Important interpretation:
- `s(x)` is entropy density
- `T` now depends on x, i.e. `T = T(x)`
- The new entropy equation describes entropy production along the front
- I do NOT want a fake shortcut that keeps T fixed while pretending to solve the entropy equation

Very important update:
Because `T = T(x)`, `muQ = muB/3 = muB(x)/3`, the microphysics coefficients
- `DQ`
- `eta`
- `gamma`
must NOT be frozen once at the beginning.
They must be treated as local functions along the profile, since they depend on the local temperature (and chemical potentials).

So compared with the old solver, the key physics change is:
- `DQ`, `eta`, `gamma` are now x-dependent through the local thermodynamic state
- do NOT keep the old “evaluate at Qstar and freeze” convention in this new entropy solver

How I want this implemented
---------------------------

1. Add a third ODE field, but use entropy flux, not T directly
Define a new ODE variable

    w(x) = s(x) * u(x)

I want the ODE system written in terms of:
- `a(x)`
- `q(x)`
- `w(x)`

not directly `T(x)`.

Reason:
- The new equation is directly an equation for `d/dx (s u)`
- Using `w = s u` avoids needing an explicit expression for `dT/dx`
- Then temperature can be reconstructed locally from the algebraic thermodynamic closure

So the physical first-order system should become

    da/dx = (q + u a) / DQ(x)
    dq/dx = gamma(x) * (a^3 + eta(x) * a)
    dw/dx = (nB_Q / T) * muK * gamma(x) * (a^3 + eta(x) * a)

where
    w = s * u

and `nB_Q` is still the far-right equilibrium quark baryon density used in the definition of `a`.

2. Keep the compact-coordinate BVP architecture
The current solver uses the compact coordinate

    s_coord = 1 - exp(-x/kappa)

with
    x = -kappa * log(1 - s_coord)
    dx/ds_coord = kappa / (1 - s_coord)

Keep that architecture.

So the BVP ODE system in the compact coordinate should become

    da/ds_coord = [(q + u a)/DQ] * dx/ds_coord
    dq/ds_coord = [gamma * (a^3 + eta * a)] * dx/ds_coord
    dw/ds_coord = [(nB_Q / T) * muK * gamma * (a^3 + eta * a)] * dx/ds_coord

where now `DQ`, `eta`, and `gamma` are local quantities evaluated from the local thermodynamic state at each mesh point.

Use the same compact-coordinate conventions and parameterization already used by `solve_steady_front_1d_aQstar_rescale_bvp(...)`.

3. Local closure must now solve for (muB, muK, T)
This is the most important change.

Right now the local closure solves for `(muB, muK)` from:
- momentum-flux constraint
- composition constraint

Now, because `T(x)` varies and `w = s u` is an ODE field, the local state at each mesh point must be reconstructed from three unknowns:

    muB(x), muK(x), T(x)

Use these three algebraic equations:

(A) momentum-flux conservation:
    Pi_QM(muB, muK, B_one_forth, T, jB) = Pi

(B) composition definition:
    ( nK(muB, muK, B_one_forth, T) - nK_Q ) / nB_Q = a

(C) entropy-flux definition:
    s_QM(muB, muK, B_one_forth, T) * u = w
where
    u = jB / nB_QM(muB, muK, B_one_forth, T)

This is the new local closure:
    given (a, w, Pi, jB) solve for (muB, muK, T)

- one unknown scalar parameter: `jB`

(BC1) interface composition:
    a(0) = aQstar

(BC2) interface composition-flux jump:

(BC3) interface temperature continuity:

We assume

    T(0-) = T(0+) = TQstar

where `TQstar` is the input temperature argument to the solver.

- solve the interface thermodynamic state `Qstar` at temperature `TQstar`
